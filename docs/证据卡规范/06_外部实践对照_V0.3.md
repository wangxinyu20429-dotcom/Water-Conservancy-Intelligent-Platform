# 证据卡外部实践对照 V0.3

查阅日期：2026-09-03。目的：给证据提取、忠实表达和验收设计提供外部依据；不是替论文做质量认证，也不把其他学科的特定报告标准直接变成本平台科研规则。

| 已查外部来源与事实 | 可借鉴原则 | 本轮产品选择与边界 |
| --- | --- | --- |
| [Cochrane Handbook 第5章：Collecting data](https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-05)讨论提取表、预试用、研究与多份报告、来源记录、提取核对及分歧处理 | 提取对象、来源、上下文和核查过程要结构化；同研究多报告须辨关系 | 使用S/C/R登记和一篇试填。Cochrane面向系统综述的独立提取要求不能被“同一人两遍”冒充；本轮单人局限显式保留，不宣称符合完整Cochrane方法 |
| [AGU Data and Software for Authors](https://www.agu.org/publications/authors/journals/data-software-for-authors)对支撑研究的数据/软件保存、引用、版本和可用性说明提出要求 | 来源、版本、持久标识和访问条件属于可审查信息 | 卡片记录作者声明与实际查到的资源状态；不因公开链接存在就声称可复现，不擅自认定论文违反期刊政策 |
| [PRISMA 2020 checklist](https://www.prisma-statement.org/prisma-2020-checklist)提供系统综述报告清单及扩展解释入口 | 不同研究类型需要不同报告字段 | 仅在系统综述模块核对检索、筛选、纳入和综合等作者实际报告；不对单篇水文模拟强套PRISMA，也不把报告清单得分当科学质量 |
| [NASEM：Reproducibility and Replicability in Science，Chapter 2](https://www.nationalacademies.org/read/25303/chapter/3)区分同输入/分析条件下的计算重现与使用新数据研究的复验 | 明确“读懂”“能访问”“运行成功”“结果核对”之间的证据差异 | 平台检查只证明相应工具行为，不能证明论文科学结果；保留作者自己的术语，说明本包使用“复现”时的实际含义 |
| [ASA 2016 关于统计显著性和p值的官方声明](https://www.amstat.org/asa/files/pdfs/p-valuestatement.pdf)指出p值不等于假设为真概率，显著性不衡量效应大小或结果重要性，判断不能只看阈值 | 结果须保留效应、设计、情景与不确定性，不能只摘“显著提高” | 数值核对包括比较基准、报告区间及原文措辞；没有报告的统计量不擅自计算或补齐 |

## 外部事实与本地选择分界

“八部分骨架、两层阅读、单人启动、C/R/U卡内编号、十二步流程和九个Issue”是依据用户需求与当前主库边界形成的产品方案，不是上述机构颁布的统一标准。“所有重要已用声明逐项核对”是本轮过程要求，不是任何工具已经做到零错误的事实。

本地现行初读生产规则已经允许用户直接提交材料，不等待两位学生或历史六篇任务。新的候选模板沿用现行八部分和证据边界，增加细粒度字段。现行生产模板、正式对象状态和主题写回契约仍由主库规则决定；本文件不替代它们。既有记录所述三份外层Word在记载位置本轮未找到，因此不声称本次读取或修订了原始Word。

实践对照支持的是可审查的设计方向。模板在真实水利论文上的适用性、操作耗时和减少错误的效果尚待试用，不把方法指南替代真实验收。
