# 文献发现到深度主题的双路线工作流

## 1. 唯一主链

本Skill按以下主链运行：

研究问题与边界 → 选择小样本或大语料路线 → 候选方向发现与人工定界 → 主题层资源分配 → 主题内关键全文排序 → 全文证据卡 → Claim准入 → 深度主题 → 有来源的综合见解 → 三类反馈 → 重跑受影响阶段 → 人工复核与导师决定。

候选主题簇、语料统计、原文Claim、综合推断和导师决定是不同对象，不能互相替代。

## 2. 路线选择

### 小样本深读路线

适用于用户已经指定Zotero集合、已有若干全文或证据卡，且目标是理解问题、比较方法或形成深度主题。依次完成：

1. 冻结研究问题、用途、时间、空间、对象和纳入排除条件；
2. 核对Zotero条目、DOI、来源版本和全文可读性；
3. 根据题名、摘要、文献类型和预期科学作用形成初步分组；
4. 人工确认候选方向和边界；
5. 选择关键全文并建立证据卡。

小样本没有足够的年度时间切片、主题稳定性或分母时，主题增长率写`not_applicable`，不得为了排序强行计算DTM或趋势。

### 大语料发现路线

适用于数百至数十万条题录，目标是发现研究结构、时空演化或候选方向。依次完成：

1. 保存数据库、完整检索式、检索日期、过滤条件、返回数量和许可边界；
2. 按DOI、数据库ID、规范化题名作者年份和版本谱系去重；
3. 保存原始题名摘要，并生成可重建的标准化文本；
4. 用LLM提取研究区域、流域、对象、过程、数据、方法和任务等结构化字段；
5. 用词典、正则或确定性规则识别水文模型、数据集和设施等可枚举对象；
6. 用主题模型形成候选簇，并通过主题一致性、重复运行、时间切片样本量和代表文献稳定性检查；
7. 计算年度主题相对热度，并使用Theil–Sen斜率估计趋势、Mann–Kendall检验趋势支持；
8. 人工审查伪主题、混合主题、边界模糊项和离群项；
9. 只把通过人工审查的候选方向送入关键全文选择。

这一路线借鉴Hu等人的LLM研究区域解析、规则识别、动态主题模型和趋势统计分工。Hu等人没有给出“年份、期刊、引用、主题增长率”的综合阅读权重，也没有用语料统计替代全文证据。

## 3. 主题增长趋势

对主题`k`和年份`y`，记录当年主题相对热度`P(k,y)`；同一年全部主题相对热度之和为1。趋势记录至少包括：

- 各年主题相关原始数量；
- 各年语料总量，即分母；
- 各年主题相对热度；
- Theil–Sen斜率和时间单位；
- Mann–Kendall统计量和显著性水平；
- 多主题检验时的多重比较处理；
- 时间切片样本量、主题稳定性、检索覆盖和分类变化。

主题趋势属于组成数据。占比上升可能来自本主题增加，也可能来自其他主题下降。趋势只表示当前语料中的关注结构变化，不能证明研究问题更重要、方法更有效或结论更正确。

## 4. 两级发现优先级

### 主题层

综合研究问题相关性、趋势、主题稳定性、语料覆盖、流域或对象缺口，决定各候选方向分配多少关键全文阅读名额。主题增长趋势只在这一层使用。

### 文献层

在同一候选方向内部，根据问题直接性、决定性缺口价值、预期科学作用、新近性、同学科同年份标准化引用表现和经核期刊信号形成先读、后读和暂缓队列。

候选发现阶段默认保留分项值和理由，不生成综合总分。只有完成预先登记的试运行、权重敏感性分析并获得导师冻结，才允许生成综合分数。任何总分都只决定阅读资源，不得进入Claim可信度。

## 5. 期刊与引用信号

经核期刊信号优先使用同一指标年度、同一JCR学科的JIF percentile；只有分区时可降级使用分区。原始JIF缺少年度和学科归一化时写`unknown`。跨学科期刊保留全部相关类别，并按事先确定的主学科或保守规则使用，不能事后挑最高值。非期刊来源写`not_applicable`。

引用信号使用同学科、同发表年份的引用百分位或有来源的标准化指标。原始被引次数、引用每年和数据库给出的不同口径不能混算。缺少归一化依据时写`unknown`。

Hu等人把一个期刊中水文相关文章的总被引次数除以文章数，作为期刊影响力。该篇均被引指标不是JCR影响因子，也不是本Skill的经核期刊信号。

## 6. 全文、Claim与主题

关键全文队列只是阅读顺序。只有全文证据卡中具有可复核定位、范围、方法、结果、限制和核验状态的L2/L3 Claim可以进入主题承重证据。题名摘要抽取、主题概率、趋势、年份、引用和期刊信号都不能直接准入Claim。

深度主题必须解释研究问题、对象与尺度、数据与测量、方法谱系、结果和知识状态、异质性与真冲突、负结果、证据边界、独立见解、反证条件以及下一步最小补证。可见科学正文不足10,000字符且材料不足时标记`blocked_source_limit`，不得填充套话。

## 7. 三类反馈

### 原文与证据卡反馈 `source_recheck`

当具体主题判断可能被某篇原文的章节、图表、数值、定义或版本改变时，回到原全文和原证据卡。反馈必须指向原卡、Claim、最小材料和停止条件。

### 语料补充反馈 `corpus_supplement`

当主题边界或判断因地区、时期、来源类型、语言、数据或方法文献缺失而不完整时，修改检索问题、检索式或纳入条件，并产生新的可追溯检索记录。当前集合未覆盖不能写成领域无人研究。

### 发现模型纠偏 `discovery_model_correction`

当LLM、词典、规则、主题模型或地理匹配出现系统性误提、漏提、错组或不稳定时，修改对应配置并在人工标注小样本上复核。模型纠偏影响既有主题成员、趋势或边界时，必须重跑受影响阶段。

## 8. 重跑和停止

- 原卡改变：重跑Claim准入、证据画像、主题综合和补核优先级；
- 新增语料：重跑去重、抽取、候选方向、趋势和关键全文队列；
- 发现模型改变：重跑标准化之后的抽取、聚类、趋势和分类审查；
- 只增加文字而不改变判断、边界、排序或下一步时停止反馈；
- 任何正式主题状态、拆分合并、Idea入口或停止决定由导师或项目授权者完成。
